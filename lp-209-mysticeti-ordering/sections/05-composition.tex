The pipelining-depth cap is the LP-217 cert mode's required-leg
slowest arrival -- at PQ-strict $\sim$\SI{5}{\milli\second} is far

$\sim$\SI{50}{\milli\second} is still within the
\SI{100}{\milli\second} cadence, so 2--3 deep pipelining holds.

\subsection{With LP-211 cross-shard}

When state is sharded across multiple chain-VMs (LP-204 Tier-2),
each shard runs its own LP-208/209 stack. A cross-shard tx group is
committed atomically by LP-211's cross-shard cert at the parent L1
-- the per-shard wave commits provide each shard's prepare-ack; the
parent L1's wave commits the cross-shard cert.

This means LP-209's ``wave'' is per-shard; LP-211's ``cross-shard
commit'' is a parent-L1 wave that references prepare-acks from $N$
shard waves. The parent L1's wave latency is the max of the
per-shard wave latencies plus the LP-217 cert at the parent L1.
