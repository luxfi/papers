\section{Halmos Symbolic Testing}


Where fuzzing samples the input space randomly, Halmos explores it exhaustively (within
loop bounds). We use Halmos for the strongest properties where fuzzing alone is
insufficient:

\begin{lstlisting}[language=Solidity,caption={Halmos symbolic test for access control}]
function check_onlyOwnerCanSetFee(
    address caller,
    uint256 newFee
) public {
    vm.assume(caller != owner);
    vm.prank(caller);

    // Must revert for non-owner
    try pool.setFee(newFee) {
        assert(false); // Should not reach here
    } catch {
        // Expected: revert
    }
}
\end{lstlisting}
