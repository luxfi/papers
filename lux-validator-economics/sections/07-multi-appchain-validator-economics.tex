\section{Multi-Appchain Validator Economics}
\label{sec:multiappchain}

\subsection{Appchain Validation Cost-Benefit}

Validating additional appchains incurs marginal hardware costs but generates additional rewards:

\begin{definition}[Appchain Validation Profit]
The marginal profit of validator $v_i$ adding appchain $k$ is:
\begin{equation}
    \Delta\pi_{i,k} = r_{i,k}^{\text{appchain}} - h_k^{\text{marginal}}
\end{equation}
where $h_k^{\text{marginal}}$ is the incremental hardware cost (CPU, storage, bandwidth) for running appchain $k$'s VM.
\end{definition}

\subsection{Optimal Appchain Portfolio}

\begin{algorithm}[H]
\caption{Optimal Appchain Selection for Validator $v_i$}
\label{alg:appchain_selection}
\begin{algorithmic}[1]
\Require Available appchains $\mathcal{K}$, hardware capacity $H_i^{\max}$
\State Sort appchains by $\Delta\pi_{i,k} / h_k^{\text{marginal}}$ (profit per cost)
\State $\mathcal{K}_i \gets \emptyset$; $H_{\text{used}} \gets h_{\text{primary}}$
\For{each appchain $k$ in sorted order}
    \If{$H_{\text{used}} + h_k^{\text{marginal}} \leq H_i^{\max}$ and $\Delta\pi_{i,k} > 0$}
        \State $\mathcal{K}_i \gets \mathcal{K}_i \cup \{k\}$
        \State $H_{\text{used}} \gets H_{\text{used}} + h_k^{\text{marginal}}$
    \EndIf
\EndFor
\State \Return $\mathcal{K}_i$
\end{algorithmic}
\end{algorithm}

This is a variant of the fractional knapsack problem, solvable in $O(|\mathcal{K}| \log |\mathcal{K}|)$ time.
