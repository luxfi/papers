\section{Future Work}
\label{sec:future}

The architecture is built and the three axes are measured; the following items are named,
not yet built, and stated as such.

\begin{enumerate}
  \item \textbf{A cheaper matching representation.} A \texttt{Q64.64} fixed-point matching
  path (4\,KB arenas, $64/64$ division) trades precision and ABI width for a far shorter
  critical path and a far smaller working set, on top of the billions-of-orders/sec the
  \texttt{uint256} path already delivers (Section~\ref{subsec:billion-matching}). It is not
  yet built; it carries a precision/ABI tradeoff that must be specified before it can replace
  the \texttt{uint256} path under the same parity gate.
  \item \textbf{A compact arena.} The current per-book arena is large and mostly empty, which
  causes a cache cliff beyond roughly 50--75\,k markets (Section~\ref{sec:gpu-matching}). A
  compact arena is the lever for very high market counts.
  \item \textbf{The production-batch \texttt{starkfri} AIR.} The measured 986 verifies/s is
  for a toy AIR; the production DEX-batch AIR (boundary and transition constraints over many
  trace rows) is scaffolded and not yet measured, and will verify slower
  (Section~\ref{sec:rollup}).
  \item \textbf{Decentralizing the D-Chain.} The D-Chain is a single-operator venue today.
  Decentralizing it to many validators requires committing the matching representation at the
  state layer for cross-architecture agreement and moving finality from P3Q attestation to
  \texttt{starkfri} validity proofs (Sections~\ref{sec:determinism}, \ref{sec:security}).
  \item \textbf{Private order flow at scale.} Homomorphic bootstrapping is orders of magnitude
  below the attestation rate (Section~\ref{sec:rollup}); making private order flow
  competitive with the public path is an accelerator-bound problem on the FHE side.
  \item \textbf{Derivative markets.} Perpetual futures and options settle naturally on the
  CLOB with oracle-fed mark prices and a liquidation engine; these are product surfaces above
  the matching and settlement primitives described here.
\end{enumerate}
