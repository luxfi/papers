\subsection*{LP-137 substrate-wide coverage gate}

The LP-137 9-chain substrate (cevm + 5 new VMs: PlatformVM, XVM,
AIVM, BridgeVM, MPCVM) gates CI at $\geq 96\%$ line coverage on the
CPU reference oracle of every VM (the byte-equivalence ground truth
against which every GPU backend is asserted). cevm reports
\textbf{95.78\%} TOTAL line coverage and \textbf{96.51\%} on the
dominant translation unit \texttt{quasar\_gpu\_engine.mm}; the 5
new VMs average \textbf{97.96\%} oracle line coverage (LP-137-COVERAGE.md,
2026-04-27). LLVM source-based instrumentation
(\texttt{-fprofile-instr-generate -fcoverage-mapping}) on Apple
Clang 17 / clang on CUDA hosts; per-VM \texttt{COVERAGE.md} files
include full per-file breakdowns.
