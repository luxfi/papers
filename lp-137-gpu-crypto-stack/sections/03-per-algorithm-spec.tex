\section{Per-Algorithm Specification (Pointer)}
\label{sec:per-algorithm-spec}

LP-137 carries no per-algorithm formal content. Each primitive in the stack is specified in its own LP, organized one LP per algorithm. The full per-algorithm index lives in \texttt{LP-INDEX.md} of \texttt{luxfi/lps}. The scope covered here is the Lux GPU substrate (\S\ref{sec:architecture}), the byte-equality contract (\S\ref{sec:determinism-harness}), the GPU-residency invariant, and the production performance methodology (\S\ref{sec:performance}).

Per-algorithm LPs of immediate relevance to LP-137 are summarized in Table~\ref{tab:lp-pointers} below; consult each LP for parameters, algorithm pseudocode, KAT sources, implementation paths, and security analysis.
