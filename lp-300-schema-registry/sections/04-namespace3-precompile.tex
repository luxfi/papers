\section{Namespace 3 -- EVM Precompile slot}
\label{sec:precompile}

EVM precompiles live in three disjoint address bands and a handful
of legacy / stateful clusters. Each row is owned by exactly one LP
(``Owner LP'') and optionally co-owned by a wrapper LP that attaches
a higher-level construction on top of the raw primitive.

The address bands and their authoritative owners:

\begin{itemize}[leftmargin=2em,nosep]
\item \texttt{0x000B..0x0FFF} -- Ethereum-compatible / Lux core (LP-078)
\item \texttt{0x011xxx} -- Federation / governance (LP-0011)
\item \texttt{0x012xxx} -- Post-quantum cryptography (LP-0120)
\item \texttt{0x02xxxxxx} -- Subnet-EVM-style stateful range (LP-3520 / LP-078)
\item \texttt{0x6010..0x9FFF} -- Application-layer (DEX, AI)
\item \texttt{0xB000..0xBFFF} -- Blob / KZG
\item \texttt{0x020000+} -- Reserved for future precompile blocks
\end{itemize}
