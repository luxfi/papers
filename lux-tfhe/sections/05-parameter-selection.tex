\begin{proposition}[Security Level]
\label{prop:security}
The PN10QP27 parameter set provides $\geq 128$-bit classical security and $\geq 100$-bit
quantum security, matching the security of the standard TFHE parameter set.
The LWE instance has dimension $n = 1024$ and noise ratio $\alpha = \sigma\sqrt{2\pi}/q \approx 2^{-23.4}$,
for which the best known attacks (primal and dual lattice attacks) require $\geq 2^{128}$
classical operations.
\end{proposition}
