\section{FHE VM Integration}

\label{sec:fhevm}

The threshold TFHE scheme integrates with the Lux FHE VM as follows:

\begin{enumerate}[nosep]
\item \textbf{Encryption}: Users encrypt inputs using the network's public key.
\item \textbf{Evaluation}: EVM precompiles execute FHE gates on encrypted data without
decryption. Each Solidity opcode maps to a sequence of TFHE gates.
\item \textbf{Decryption}: When a smart contract requests decryption, the threshold
decryption protocol distributes the task among $t$-of-$n$ validators.
\end{enumerate}

The \texttt{FHE.sol} library exposes FHE operations as Solidity functions:
\texttt{FHE.add}, \texttt{FHE.sub}, \texttt{FHE.mul} for encrypted unsigned integers,
and \texttt{FHE.lt}, \texttt{FHE.eq} for encrypted comparisons.
