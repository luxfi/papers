\section{What is blockchain?}

It is important to understand the differences between cryptocurrencies and blockchain technology. A blockchain is a digital, secure, immutable register or record of transactions (a ledger). ``Block'' describes the way this ledger organizes transactions into blocks of data, which are then organized in a ``chain'' that links to other blocks of data. The links make it easy to see if anyone has changed any part of the chain, which helps the system protect against invalid transactions.
