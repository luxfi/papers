\begin{abstract}
LP-221 specifies the dedicated EVM precompile at slot
\texttt{0x012220} for verifying strict-PQ STARK proofs. The verifier
is a Plonky3 fork with the classical-curve surface stripped out:
\textbf{FRI}~\cite{frieprint} low-degree testing over the
\textbf{Goldilocks} 64-bit prime field, \textbf{cSHAKE256}
(FIPS~202~/ SP~800-185)~\cite{fips202,sp800185} Merkle commitments,
no KZG, no pairings, no elliptic-curve arithmetic. The reference
implementation at \texttt{lux/precompile/starkfri/} (5 files, 22
tests passing under \texttt{-race} in \SI{1.376}{\second} on
darwin/arm64) registers under config key \texttt{starkfriVerify}.
LP-221 is the dedicated allocation that LP-300~\S``Post-quantum
precompile registry'' had recorded as the displaced-Plonky3-fork
placeholder pending dedicated LP allocation. LP-221 is orthogonal
to LP-218: LP-218 owns slot \texttt{0x012205} for PQ
\emph{signature} verification (Pulsar~/ Corona~/ Magnetar
kind-byte dispatched); LP-221 owns slot \texttt{0x012220} for PQ
SNARK \emph{proof} verification. One slot for signatures, one slot
for SNARK proofs, two disjoint use cases, zero overlap. The on-chain
wire format pins \texttt{VersionV1=0x01}, \texttt{MagicHeader="P3Q1"}
preserved verbatim from the pre-rename era for proof-artifact
byte-stability (EasyCrypt~/ Lean~/ Jasmin~/ dudect), and
\texttt{MinInputLength=13} (1 version + 4 proof-len + 4 magic + 4
public-input-len). Gas schedule is \texttt{BaseVerifyGas=200{,}000 +
PerByteGas=10}, sized to the CPU verify cost (\SIrange{5}{10}{\milli\second}
per typical \SI{30}{\kilo\byte} proof). Soundness reduces to
collision resistance of cSHAKE256 modeled as a random oracle; the
parameter set used by the audited backend crate fixes the soundness
error at $\le 2^{-100}$. Completeness is~$1$.
\end{abstract}
