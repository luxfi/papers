\begin{abstract}
\noindent
Quasar is the Lux Network's post-quantum (PQ) consensus suite.
Per-round finality is asserted via a single wire-format certificate,
the \emph{QuasarCert}, that composes up to five independent
cryptographic legs: a BLS12-381 aggregate signature (classical fast
path, discrete logarithm), a Pulsar threshold ML-DSA-65 signature
(Module-LWE), an optional Corona threshold signature (Ring-LWE), an
optional Magnetar threshold SLH-DSA signature (hash-based), and a
Z-Chain Groth16 proof rolling up $N$ per-validator ML-DSA-65 identity
signatures into a 192-byte SNARK. Three cert profiles ---
\textbf{Pulsar} (BLS + Pulsar + Z-Chain Groth16; PQ floor),
\textbf{Aurora} (adds Corona; intra-lattice diversity), and
\textbf{Polaris} (adds Magnetar; cross-family) --- select which legs
are populated. Each profile is independently selectable per Lux
chain.

This paper formalizes the QuasarCert wire format, the three cert
profile compositions, and the cross-primitive composition theorems.
The central security claim is conjunctive hardness diversification:
forging a profile-$\mathcal{P}$ cert requires forging \emph{every}
populated leg, each backed by an independent hardness assumption.
We document the production deployment topology on Lux primary
network's Q-Chain finality and the gating from the current Pulsar
profile to the Aurora and Polaris profiles as the underlying
Corona and Magnetar primitives reach Tier A audit status. The
Pulsar profile is currently production-deployed; Aurora and
Polaris are operationally ready and gated on primitive maturity.

\textbf{Scope.} This is the umbrella paper for the Quasar suite.
The per-primitive papers --- LP-020 (Quasar consensus), LP-073
(Pulsar), Corona, Magnetar, and the Lean-mechanized soundness proof
at \texttt{quasar-cert-soundness.tex} --- own the per-leg security
arguments. This paper owns the cross-primitive composition: the wire
format that binds the legs into a single envelope, the verifier that
enforces the conjunction, and the theorems that bound forgery by the
minimum advantage across populated legs.
\end{abstract}

composition proofs);
\texttt{github.com/luxfi/consensus} (consensus engine, QuasarCert wire

\texttt{github.com/luxfi/corona} (threshold R-LWE primitive, v0.6.0);
\texttt{github.com/luxfi/magnetar} (threshold SLH-DSA primitive,
v0.2.0);
\texttt{github.com/luxfi/crypto} (BLS / ML-DSA / SLH-DSA primitives);
\texttt{github.com/luxfi/threshold} (threshold MPC protocol library);
\texttt{github.com/luxfi/chains/quantumvm} (Z-Chain Groth16 rollup VM).

\noindent\textbf{Build.}
\texttt{GOWORK=off go build ./...} and
\texttt{GOWORK=off go test ./...} in
\texttt{luxfi/consensus}; per-primitive build and KAT vectors are
documented in each repo's \texttt{README.md} and \texttt{SPEC.md}.

\noindent\textbf{Hardware tested.}
Apple M1 Max (10 cores, darwin/arm64) for the measurements in
Section~\ref{sec:eval}; commodity x86\_64 Linux validators
for production deployment.

IETF \texttt{draft-irtf-cfrg-bls-signature}, RFC 9591 (FROST),

\texttt{luxfi/proofs/tla/}. Tamarin protocol verification at
\texttt{luxfi/proofs/tamarin/}.
