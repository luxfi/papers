\begin{abstract}
We present \textbf{Lux Consensus}, a physics-inspired metastable blockchain consensus protocol family that achieves sub-second finality through repeated random sub-sampling. Inspired by metastable dynamics in physical systems, Lux employs a family of consensus protocols---Slush, Snowflake, Snowball, and Avalanche---each building upon the prior with stronger safety guarantees. The core mechanism leverages network disorder: validators repeatedly query random peers and adopt the majority preference, driving the system toward one of two metastable states with probability approaching one. Unlike classical BFT protocols requiring $O(n^2)$ message complexity, Lux achieves consensus with $O(kn \log n)$ messages for $n$ validators and security parameter $k$, enabling thousands of validators without performance degradation. We implement these protocols within a multi-chain architecture supporting heterogeneous virtual machines (X-Chain, C-Chain, P-Chain, and subnet-specific chains), each optimized for distinct workloads. Empirical evaluation demonstrates 1--2 second time-to-finality with 2,000+ validators under Byzantine conditions, maintaining liveness and safety with up to $f < n/4$ adversarial nodes in the parameterized threat model.
\end{abstract}
