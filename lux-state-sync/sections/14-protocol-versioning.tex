\section{Protocol Versioning}
\label{sec:versioning}

The state sync protocol includes a version negotiation phase:

\begin{enumerate}
    \item \textbf{v1}: Basic chunk download with Merkle proofs (initial release).
    \item \textbf{v2}: Incremental sync support and multi-source download.
    \item \textbf{v3}: Compressed chunk transfer (Snappy/LZ4) reducing bandwidth by 40\%.
    \item \textbf{v4}: (Planned) Verkle tree support for sub-linear proof sizes.
\end{enumerate}

Peers negotiate the highest mutually supported version during the handshake.
