\subsection{Provider Interface}

Each provider implements a common interface:

\begin{lstlisting}[language=Go,caption={Provider interface.}]
type Provider interface {
    // Identification
    ID() ProviderID
    Name() string
    Type() VenueType // OnChain, ATS, Traditional

    // Market data
    Quote(ctx context.Context, req QuoteRequest) (*Quote, error)
    OrderBook(ctx context.Context, security SecurityID) (*Book, error)

    // Execution
    Submit(ctx context.Context, order Order) (*Execution, error)
    Cancel(ctx context.Context, orderID OrderID) error
    Status(ctx context.Context, orderID OrderID) (*OrderStatus, error)

    // Capabilities
    Supports(security SecurityID) bool
    MaxOrderSize(security SecurityID) uint64
    MinOrderSize(security SecurityID) uint64
    Jurisdictions() []Jurisdiction
    SettlementTime() time.Duration

    // Health
    Ping(ctx context.Context) error
    Latency() time.Duration
}
\end{lstlisting}
