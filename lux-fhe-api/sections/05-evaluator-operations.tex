\section{Evaluator Operations}


\subsection{Boolean Gates}

The evaluator supports standard boolean gates, each followed by automatic bootstrapping:

\begin{table}[h]
\centering
\begin{tabular}{@{}ll@{}}
\toprule

\midrule

\subsection{Error Handling}

Every operation returns an explicit error. Common error conditions:

\begin{itemize}
\item \textbf{Type mismatch}: Attempting to add a \texttt{FheUint8} to a \texttt{FheUint32}. Rejected at the API boundary.
\item \textbf{Nil ciphertext}: Passing an uninitialized ciphertext. Returns \texttt{ErrNilCiphertext}.
\item \textbf{Parameter mismatch}: Evaluating with keys generated for different parameters. Returns \texttt{ErrParamMismatch}.
\end{itemize}

No operation panics. All errors are returned, never swallowed.
