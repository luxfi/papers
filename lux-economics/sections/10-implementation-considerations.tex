\subsection{P-Chain Modifications}

Implementing the full suite of appchain economic mechanisms requires the following P-Chain
changes:

\begin{enumerate}[leftmargin=1.5em]
  \item New transaction type \texttt{SetAppchainEconomicsParams} allowing appchain creators
    to publish their fee sharing and LWES parameters;
  \item Modified \texttt{AddAppchainValidator} transaction to include capacity commitment
    $K$ and opt-in reward acceptance;
  \item New epoch-based reward distribution logic collecting SSF and distributing to
    Primary Network validators;
  \item Elastic scaling signals as P-Chain events monitored by the LRP node sidecar.
\end{enumerate}

\subsection{Smart Contract Infrastructure}

C-Chain contracts required:

\begin{enumerate}[leftmargin=1.5em]
  \item \texttt{AppchainTokenFactory}: Deploys ERC-20 appchain tokens with LWES emission schedule built in;
  \item \texttt{SSFCollector}: Receives security surcharge payments from appchains;
  \item \texttt{CrossAppchainMEVOracle}: Monitors Teleporter events and runs MEV auctions;
  \item \texttt{ElasticScalingCoordinator}: Issues expansion/ejection signals and manages
    validator admission queues.
\end{enumerate}
