\section{Solvency State Machine}

\label{sec:state-machine}

The protocol defines exactly four solvency states. All transitions are deterministic given $B$ and $L$. No transition requires operator discretion.

\subsection{States}

\begin{definition}[Healthy]
$B \geq L / \lambda$ and $B \geq L$. All operations permitted.
\end{definition}

\begin{definition}[Restricted Mint]
$B < L / \lambda$ but $B \geq L$. Equity buffer depleted; principal still covered. Mint \textbf{disabled}. Burn and release allowed. Strategy deployment halted; withdrawals initiated.
\end{definition}

\begin{definition}[Emergency]
$B < L$. System undercollateralized on principal basis. Mint \textbf{disabled}. Burn allowed. Release governed by emergency policy. Strategy withdrawals \textbf{forced}. Recovery governance \textbf{active}.
\end{definition}

\begin{definition}[Recovery]
Post-emergency transitional state. Mint disabled until $E/B \geq 1 - \lambda$. Burn and release allowed. Exit requires governance or MPC quorum.
\end{definition}

\subsection{Auto-Pause Trigger}

An accelerated emergency trigger fires when $B < \alpha \cdot L$ with $\alpha = 0.985$. This immediately halts all outbound operations except burns.
