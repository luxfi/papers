\begin{abstract}
We present a rollup pattern where the sequencer signs each batch
with a Pulsar threshold signature, the parent L1 verifies that
signature via the P3Q precompile at EVM slot \texttt{0x012205}, and
the rollup state inherits the parent L1's QuasarCert finality. No
rollup-side validator set, no fraud-proof bond for the
cryptographic path, no codec hop on the sequencer-to-L1 wire.
Optimistic and ZK variants share the same envelope; the difference
is whether the batch carries a STARK/Groth16 proof of correct
execution. End-to-end commit latency from sequencer batch close to
parent L1 finality at PQ-strict: \SI{10}{\milli\second}--\SI{50}{\milli\second}.
This paper expands on LP-218
(\texttt{lps/LP-218-zap-p3q-pq-rollup.md}) with the
six-step pattern as a numbered list (alongside the user's five-step
framing), the four wire envelopes
(\texttt{0xE0}--\texttt{0xE3}), the P3Q precompile interface and
honest gas accounting, the two rollup modes (optimistic vs ZK), and
the inherited cert mode contract that ties rollup finality to the
parent L1's LP-217 mode.
\end{abstract}
