\section{Implementation}
\label{sec:warp-implementation}
%% ====================================================================

The shipping implementation lives in two Go packages: \texttt{github.com/luxfi/warp} (the root package) and \texttt{github.com/luxfi/warp/pulsar} (the Pulse path). The split exists so the root package does not import the Pulsar kernel directly; the dispatch surface is the small \texttt{PulseVerifier} interface, with the concrete kernel-driven verifier in the subpackage.

\subsection{The single parser}

The root \texttt{warp} package exposes one envelope parser, \texttt{ParseEnvelope}. There is no version-byte dispatcher and no cross-version fallback: \texttt{ParseEnvelope} requires the ZAP magic and the \texttt{kindEnvelope} byte, then reads the fields in order through a strict, bounds-checked cursor (\texttt{zapReader}).

\begin{verbatim}
func ParseEnvelope(b []byte) (*Envelope, error) {
    if len(b) == 0 { return nil, ErrEnvelopeEmpty }
    if len(b) > MaxEnvelopeSize { return nil, ErrEnvelopeTooLarge }

    r := newZapReader(b)
    if err := r.expectMagic(); err != nil {        // "LWZP"||0x01
        return nil, err
    }
    kind, err := r.u8()
    if err != nil { return nil, err }
    if kind != kindEnvelope {                       // 0x02
        return nil, fmt.Errorf("%w: envelope kind 0x%02x",
            ErrInvalidMessage, kind)
    }

    e := &Envelope{}
    if e.Message, err = parseMessage(r); err != nil { return nil, err }
    if e.Beam, err = parseBeam(r); err != nil { return nil, err }
    if e.PulseSig, err = r.varbytes(); err != nil { return nil, err }
    if e.MLDSACertSet, err = r.varbytes(); err != nil { return nil, err }
    if err := r.end(); err != nil { return nil, err } // reject trailing
    if err := e.Verify(); err != nil { return nil, err }
    return e, nil
}
\end{verbatim}

Legacy RLP bytes (lead \texttt{0xc0}--\texttt{0xff} or the bare \texttt{0x02}) fail \texttt{expectMagic} and are rejected; there is no in-band lift of legacy v1 bytes into the envelope. \texttt{ParseMessage} is the analogous single parser for a standalone $\mathsf{Message}$.

\subsection{The PulseVerifier interface}

\begin{verbatim}
type PulseVerifier interface {
    VerifyPulse(env *Envelope) error
}
\end{verbatim}

The root package's \texttt{VerifyWithOptions} (and the PQ-only entrypoint \texttt{VerifyPQLanes}) accept a \texttt{PulseVerifier} and an \texttt{MLDSACertSetVerifier} through a \texttt{VerifyOptions} struct. Production code wires \texttt{warp/pulsar/KernelVerifier} (the concrete Pulsar-kernel-driven verifier). Tests wire a stub \texttt{PulseVerifier} that records calls without invoking the kernel.

The split keeps the import graph clean: the root \texttt{warp} package does not import the Pulsar kernel (\texttt{github.com/luxfi/corona}), so it has no dependency on the lattigo deserializer; downstream consumers that want only the Beam path do not pay for the lattigo dependency. The concrete \texttt{KernelVerifier} lives in the \texttt{warp/pulsar} subpackage, which imports the kernel.

\subsection{The KernelVerifier flow}

\begin{enumerate}[leftmargin=2em,nosep]
  \item The envelope must carry a non-empty Pulse (\texttt{env.HasPulse()}); otherwise \texttt{ErrPulseAbsent}. (The Beam-only path never reaches here --- \texttt{VerifyPQLanes} skips an absent lane unless \texttt{RequirePulse}.)
  \item Resolve $(\mathsf{SourceChainID}, \mathsf{SourceKeyEraID}, \mathsf{SourceGeneration})$ via the \texttt{GroupKeyResolver} to obtain $(\mathsf{GroupKey}, \mathsf{suiteID})$.
  \item Check \texttt{suiteID} matches the envelope's resolved \texttt{HashSuiteOrDefault()}; return \texttt{ErrSuiteMismatch} on mismatch.
  \item Recompute $D = \texttt{env.Message.ID()}$ and build the signing bytes $\texttt{PulseSigningBytes}(D) = \text{``LUX-WARP-ZAP-PULSE-v1''} \,\|\, D$. Because $D$ folds \texttt{SourceNebulaRoot} / \texttt{SourceKeyEraID} / \texttt{SourceGeneration} / \texttt{HashSuiteID} / \texttt{SourceChainID} / \texttt{NetworkID} / \texttt{Payload}, verifying over these bytes binds the Pulse to every one of them.
  \item Validate the Pulse wire bytes via the four-layer guards (Section~\ref{sec:fuzz-vuln}): outer wire-size cap, per-lane frame cap, frame walker, defer-recover.
  \item Deserialize via \texttt{DeserializePulse} into a \texttt{corona.Signature}.
  \item Verify via $\texttt{corona.Verify}(\mathsf{GroupKey}, \texttt{PulseSigningBytes}(D), \mathsf{signature})$; return \texttt{ErrPulseVerifyFailed} on rejection.
\end{enumerate}

The Beam verification (BLS aggregate over $\text{``LUX-WARP-ZAP-BEAM-v1''}\,\|\,D$) is run by \texttt{VerifyEnvelope}; the Pulse and ML-DSA lanes are additive. A destination chain that wants the full Horizon path wires all lanes via \texttt{VerifyWithOptions} and Prism-binds them via the \texttt{HorizonCertificate} helper (\texttt{warp/pulsar}).

  \item \texttt{warp/pulsar/pulsar\_test.go}: 100\% pass. End-to-end ceremony + sign + serialize + deserialize + verify; tampered-envelope-field rejection.
  \item \texttt{warp/pulsar/fuzz\_pulse\_test.go}: zero panics in 60 s.
  \item \texttt{warp/pulsar/fuzz\_horizon\_cert\_test.go}: zero panics in 60 s.

\subsection{Cross-implementation parity}

The Go canonical (\cite{warpgo}) is the byte oracle. The wire format is normative; any other-language implementation must produce byte-equal envelopes. The KAT vectors gate every release: fuzz seeds + a representative real-ceremony Pulse + the Mar-3 exploit input, all checked into \texttt{warp/pulsar/testdata/}.

\subsection{Wire-format / lane tests}

\begin{itemize}[leftmargin=2em,nosep]
  \item \texttt{TestParseEnvelopeRejectsLegacyRLP}: \texttt{ParseEnvelope} rejects legacy RLP bytes at the magic check (the wire boundary is mutual --- legacy decoders likewise reject the ZAP magic because \texttt{'L'} = \texttt{0x4c} is below RLP's \texttt{0xc0} list floor).
  \item \texttt{TestEnvelopeRoundTrip}: \texttt{Envelope.Bytes()} $\to$ \texttt{ParseEnvelope} produces a byte-equal envelope.
  \item \texttt{TestEnvelopeEmptyOptionalLanes}: an envelope with both PQ lanes carried as empty \texttt{u32(0)} frames round-trips and verifies on the Beam-only path.
  \item \texttt{TestParseEnvelopeRejectsTrailingBytes} / \texttt{TestParseEnvelopeRejectsNonCanonicalBitset}: canonicality enforcement on decode.
  \item \texttt{TestMessageIDIsLegacyKeccak} / \texttt{TestLaneSigningBytesDistinct}: the digest $D$ is legacy Keccak and the four lane DSTs are pairwise distinct.
\end{itemize}

All pass on the v1.22.0 tag.
