\section{Reproducibility}

\label{app:reproduce}

The complete benchmark suite is available at:
\begin{center}
\texttt{https://github.com/luxfi/consensus-benchmarks}
\end{center}

\noindent To reproduce:
\begin{verbatim}
git clone https://github.com/luxfi/consensus-benchmarks
cd consensus-benchmarks
make setup        # Pull all protocol binaries
make bench-all    # Run complete benchmark suite (~4 hours)
make report       # Generate tables and figures
\end{verbatim}

\noindent Hardware requirements: minimum 21 bare-metal nodes across 3 datacenters with
25\,Gbps networking. Cloud VMs introduce uncontrolled jitter and are not recommended for
reproducible benchmarking.
