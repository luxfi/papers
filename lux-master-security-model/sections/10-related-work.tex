\section{Related Work}

\label{sec:related}

Gavin Wood's Ethereum Yellow Paper~\cite{wood2014ethereum} specifies the EVM but does
not provide a security model or threat analysis. The Bitcoin whitepaper~\cite{nakamoto2008bitcoin}
provides a probabilistic security argument for proof-of-work but does not address
quantum threats, economic adversaries, or formal verification.

Buterin et al.~\cite{buterin2020combining} analyze the combination of finality
gadgets with available chains but do not address post-quantum security. The NIST
post-quantum standardization process~\cite{fips204} provides security proofs for
individual primitives but does not address their composition in a blockchain context.

Our contribution is a \emph{complete} security model that spans all layers,
addresses all adversary classes, and makes every assumption explicit.
