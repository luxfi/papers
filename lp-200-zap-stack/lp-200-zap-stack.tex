\begin{abstract}
We present the Lux ZAP Stack, a blockchain architecture in which a
single binary buffer is the wire format, the in-memory representation,
the on-disk record, and the snapshot stream. There is no
\texttt{codec.Manager}, no reflection-driven marshal, no encode/decode
hop between mempool and state. Each of ten layers does exactly one
job; each consumes its predecessor as bytes and produces its successor
as bytes. The architecture is the umbrella for LPs 022, 023, 182, 184,
185, 186, 201, 205, 208, 209, 210, 211, 217, and 218. Measured
head-to-head against the reflection codec \texttt{avalanchego} master
still runs, ZAP parses a transaction $73\times$ faster, validates a
\num{1000}-tx block $70\times$ faster, and --- because a validated block
stays as bytes with light views rather than a materialized Go object
graph --- holds a live block in $114\times$ less resident memory
(\SI{17}{\kilo\byte} vs \SI{1990}{\kilo\byte}). This paper expands
LP-200 (\texttt{lps/LP-200-zap-stack.md}) with the layer model, the ten
decomplected concerns, the measurement methodology, and the explicit
composition table tying the umbrella to its sibling LPs.
\end{abstract}
