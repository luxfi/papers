\section{Future Work}

The ZAP Stack umbrella is the architectural commitment. Future work
attaches to one of the ten layers:

\begin{itemize}[leftmargin=2em,nosep]
\item \textbf{LP-201} (sibling, simultaneous landing): QUIC + ZAP +
  mDNS + DHT replaces \texttt{luxfi/p2p}. Validator and node
  discovery becomes mDNS on LAN, Kademlia DHT on WAN. Tx and block
  gossip becomes QUIC streams carrying ZAP frames.
\item \textbf{LP-202} (pipelining contract): atomic-unwind primitives
  for cross-layer composition. Per-block pipeline stages
  (Select/Build/Sign) that LP-205 instantiates at depth 3.
\item \textbf{LP-203} (GPU verify): Blackwell sm\_120 kernel that
  saturates the layer-6 validator pipeline. Per-leg dispatch lets
  PQ-fast/strict/heavy modes share kernels without cross-leg
  contention.
\item \textbf{LP-204} (network of blockchains): tier-1 / tier-2 /
  tier-3 hierarchy. Tier-3 rollups inherit cert finality from their
  parent L1 (LP-218).
\item \textbf{LP-205} (pipelined Quasar): HotStuff-style 3-deep
  pipeline at the layer-9 consensus stage.
\item \textbf{LP-208} (DAG mempool): per-validator header DAG for
  $\mathrm{sum}$-bounded throughput in place of
  $\mathrm{min}$-bounded mempool admission.
\item \textbf{LP-209} (Mysticeti ordering): total-order on the LP-208
  DAG; the leader-anchored wave commits replace the per-block
  round-blocking commit.
\item \textbf{LP-210} (Block-STM): optimistic parallel execution
  on ZapDB MVCC; layer-7 executor scales with core count.
\item \textbf{LP-211} (cross-shard atomic commit): cross-VM atomic
  finality via parent-L1 QuasarCert.
\item \textbf{LP-217} (cert profile modes): operator-facing PQ-off /
  PQ-fast / PQ-strict / PQ-heavy ladder over the LP-182 cert.
\item \textbf{LP-218} (P3Q PQ rollup): rollup envelopes at schema
  range 0xE0--0xEF; Pulsar threshold sig verified on parent L1 via
  P3Q precompile at EVM slot 0x012205.
\end{itemize}

Each LP is one layer's job, completed. The architecture is finished.
The remaining work is the migration ledger documented in
Section~\ref{sec:composition}.
