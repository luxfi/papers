\subsection{Reading the table}

Every cell in the ``Layer'' column points to one row of
Table~\ref{tab:tenlayer}. An LP that spans multiple layers (LP-202
pipelining touches ZapDB layer~1 and the executor layer~7; LP-218
rollup touches the frame layer~0, the schema layer~2, and the
executor layer~7) is honestly multi-layer; we do not pretend
otherwise.

\subsection{What is NOT yet decomplected}

Honest accounting. The architecture is the ten-layer model; the
following are residual migrations of legacy code paths to the
already-decomplected architecture, not architectural blockers.

\begin{itemize}[leftmargin=2em,nosep]
\item Twelve \texttt{codec.Manager} imports remain in the node. The
  \texttt{Tx.Sign} cascade in \texttt{platformvm} and \texttt{xvm}
  still routes through \texttt{codec.Manager} for the signing step.
  The wire format on either side of Sign is ZAP; the bridge is a
  transitional shim.
\item The legacy \texttt{lux/codec/} module is not yet archived.
  Transitively pulled via \texttt{luxfi/vm/chains/atomic}. Module
  deletion is gated on the \texttt{Tx.Sign} migration above.
\item \texttt{luxfi/p2p} still imported in eleven files. LP-201
  replaces it with QUIC + ZAP + mDNS + DHT. The replacement is in
  flight, not landed.
\item \texttt{service/info} blocked on \texttt{luxfi/p2p} upstream
  codec/jsonrpc. The info-service public API still speaks the legacy
  jsonrpc envelope on top of \texttt{luxfi/p2p}'s codec. Replaced
  when LP-201 lands.
\end{itemize}

None of the above mutate the architecture. The architecture is the
ten-layer model. These are residual migrations.
