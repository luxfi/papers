\section{Translation Layer: Avalanche-isms to Lux Native}
\label{sec:translation}

The Lux substrate began as a fork of \texttt{ava-labs/avalanchego} in early
2020, but as of June 2026 the source tree contains zero references to
\texttt{ava-labs} or \texttt{avalanchego} import paths (verified by recursive
grep across the Go workspace). The protocol, wire format, consensus engine,
post-quantum stack, and GPU/C++ execution layer are Lux-original. What
remains shared is structural inheritance: the P/X/C-chain triplet shape, the
SLIP-0044 coin-type, and BIP-44 derivation. This section catalogs the
terminology mapping for engineers migrating between literature.

\subsection{Source-code anti-patterns to scrub}

The Go source tree under \texttt{\textasciitilde/work/lux/node} and
\texttt{\textasciitilde/work/lux/consensus} contains zero \texttt{Avalanche},
\texttt{Snowman}, \texttt{Snowball}, \texttt{Avax}, or \texttt{Fuji} string
literals in non-test \texttt{*.go} files. The remaining occurrences are:

\begin{itemize}[leftmargin=1.4em,topsep=0.2em,itemsep=0.1em]
  \item Academic citations in \texttt{consensus/paper/} and
        \texttt{papers/} \texttt{.tex} sources (correct attribution).
  \item Upstream forks (\texttt{geth/}, \texttt{coreth/}) that retain
        their own provenance.
  \item Third-party vendored modules (\texttt{kms/vendor/} MinIO SDK
        contains \texttt{api-putobject-snowball.go} --- unrelated AWS
        Snowball).
\end{itemize}

The 15 \texttt{Subnet}-prefixed identifiers in
\texttt{node/vms/platformvm/txs/zap\_native/} are forward-compatibility
shims for the \texttt{ConvertNetworkToL1Tx} and \texttt{TransformChainTx}
migration paths (subnet $\to$ L1 conversion, the Lux analog of Etna).
