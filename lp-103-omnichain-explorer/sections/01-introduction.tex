\section{Introduction}


Block explorers are critical infrastructure for any blockchain network, providing transaction
transparency, contract verification, and developer tooling. The dominant open-source explorer,
the traditional multi-service EVM explorer stack, requires multiple services, PostgreSQL,
Redis, and typically six Docker containers for a production deployment. This operational
complexity is a significant barrier for new chains and white-label deployments.

We present a clean-room reimplementation that achieves full EVM explorer coverage while fundamentally simplifying the architecture:

\begin{itemize}
  \item \textbf{Single binary}: One statically-linked Go executable replaces all prior explorer services
  \item \textbf{Embedded storage}: SQLite WAL mode with per-chain isolation (no PostgreSQL)
  \item \textbf{Embedded frontend}: Next.js static export served via \texttt{go:embed}
  \item \textbf{PQ encrypted backups}: Continuous WAL streaming to S3 with ML-KEM-768 + X25519
  \item \textbf{Omni-chain}: Native support for 9 chain types and 100+ external chains
  \item \textbf{White-label}: Zero branding in code, runtime-configurable
\end{itemize}
