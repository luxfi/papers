\section{Related Work}


LP-102~\cite{lp102} defines the encrypted SQLite replication standard used by the backup
system. The G-Chain (GraphVM) provides native cross-chain GraphQL queries as described in
the Lux node architecture. The ZAP wire protocol~\cite{zap} is used for high-performance
node-to-indexer communication.
