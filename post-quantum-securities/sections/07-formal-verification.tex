\section{Formal Verification}

\label{sec:formal}
%% =====================================================================

The post-quantum precompiles are formally verified in the
\texttt{lux/proofs} repository:

\begin{itemize}[nosep]
  \item \texttt{Crypto.MLDSA}: correctness and EUF-CMA security model.
  \item \texttt{Crypto.MLKEM}: IND-CCA2 security model, decapsulation
        correctness.
  \item \texttt{Crypto.SLHDSA}: hash-based security reduction,
        statelessness.
  \item \texttt{Crypto.Hybrid}: best-of-both-worlds composition
        theorem.
  \item \texttt{Crypto.Corona}: lattice-based threshold signatures
        for post-quantum MPC.
\end{itemize}
