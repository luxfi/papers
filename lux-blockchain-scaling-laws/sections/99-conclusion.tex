\section{Conclusion}
\label{sec:conclusion}

We presented the first measured scaling laws for post-quantum
threshold consensus on heterogeneous hardware (CPU, Metal, WGSL via
wgpu-native), grounded in $30$ data points across $10$ batch sizes
and $3$ backends running the canonical Lux Pulsar NTT primitive.

The single sharpest finding: \textbf{GPU acceleration of lattice
crypto is a story about batch size, not throughput-per-op.} On
Apple M1 Max:
\begin{itemize}[nosep]
\item Metal pays $\sim 1.5$ ms per command-buffer dispatch;
amortizing this requires $n \geq \sim 3{,}260$ polynomials per
call. Below that, CPU wins by $1$--$3$ orders of magnitude.
\item WGSL via wgpu-native pays $\sim 2.7$ ms per dispatch and
its asymptotic per-op cost is HIGHER than CPU on this hardware
($1.58$ vs $1.38$ \textmu s), so it never crosses CPU at any
finite batch size. The constant-factor gap is uint32-emulated u64
arithmetic vs Metal's native u64 path.
\item The Pulsar production hot path ($n = 2{,}688$) sits below
both crossovers. Per-validator GPU acceleration is unprofitable;
aggregator-side multi-validator batching wins (Theorem~\ref{thm:l2}).
\end{itemize}

These observations collapse into three empirical scaling laws —
the batch-size law (L1), the validator-parallelism law (L2), and the
epoch-amortization law (L3) — that together govern when a Lux
component should dispatch to GPU versus stay on CPU.

\paragraph{Production posture.}
The default for consensus paths in \texttt{luxfi/math/backend} is
\texttt{PolicyPureGo}: deterministic, no surprise, no GPU-vs-CPU
transcript-byte risk. \texttt{PolicyGPUPreferred} is opt-in for
aggregator paths and FHE evaluators, where the natural batch
crosses the $n^*$ threshold.

\paragraph{What's next.}
Three follow-on workstreams are queued but out of scope for this
paper:
\begin{itemize}[nosep]
\item NVIDIA H100 / RTX measurement on a CUDA-elevated CI runner.
\item Block-STM parallel EVM throughput under contention model.
\item End-to-end consensus + EVM + DEX + FHE pipeline measurement.

\S\ref{sec:honesty} documents the honest scope.

\paragraph{Reproducibility.}
All bench harnesses ship in tree, all KAT corpora are
deterministic, the wgpu-native dependency is one
\texttt{brew install}. The exact M1 Max numbers in this paper
re-derive within $\pm 5\%$ on a warm-CPU rerun.
