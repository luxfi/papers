\section{Related Work}

\label{sec:related}
%% =========================================================================

\paragraph{LayerZero.} Ultra Light Node architecture with configurable oracles and relayers~\cite{layerzero}. Teleport differs in using frozen wire format (no per-deployment configuration of proof structure) and threshold MPC rather than oracle-relayer separation.

\paragraph{Wormhole.} Guardian network with 19-of-19 multisig~\cite{wormhole}. Teleport uses $t$-of-$n$ threshold cryptography with $t < n$, providing liveness under $n - t$ node failures.

\paragraph{Across.} Optimistic bridge with intent-based settlement~\cite{across}. Complementary approach: fast settlement but 7-day fraud proof windows for worst case. Teleport provides MPC-attested proofs with no fraud proof delay.

\paragraph{Axelar.} Proof-of-stake validation with threshold ECDSA~\cite{axelar}. Similar threshold approach but Axelar runs its own consensus chain. Teleport leverages existing chain finality.
