\section{Application to Lux Validator Network}

\label{sec:application}

\subsection{Architecture}

In the Lux threshold validator architecture:

\begin{itemize}[leftmargin=2em]
  \item Each validator's BLS consensus key is split into $(t, n)$ shares, where
        $t = \lceil 2n/3 \rceil + 1$ and $n$ is the number of sub-parties
        (typically $n = 5$, $t = 4$ for a single validator).
  \item Sub-parties run on geographically distributed machines.
  \item Block signing uses threshold BLS (one-round, non-interactive).
  \item C-Chain transaction signing uses CGGMP21 (threshold ECDSA on secp256k1).
  \item Validator set changes trigger resharing with the new committee.
\end{itemize}
