\subsection{Trusted Setup}

The Groth16 proof system requires a structured reference string (SRS) generated via a trusted setup ceremony:

\begin{itemize}
    \item Powers-of-tau ceremony with $\geq 100$ participants.
    \item Circuit-specific phase-2 ceremony.
    \item Security: honest-majority assumption---if at least one participant destroys their toxic waste, the SRS is sound.
\end{itemize}

\subsection{Merkle Tree Management}

The incremental Merkle tree uses Poseidon hashes and supports efficient updates:

\begin{algorithm}[H]
\caption{Incremental Merkle Tree Insert}
\label{alg:merkle}
\begin{algorithmic}[1]
\Require New leaf $\ell$, current tree with $n$ leaves
\State $\mathsf{filled}[0] \gets \ell$
\State $\mathsf{index} \gets n$
\For{$i = 0$ to $d - 1$}
    \If{$\mathsf{index} \mod 2 = 0$}
        \State $\mathsf{filled}[i+1] \gets H(\mathsf{filled}[i], \mathsf{zeros}[i])$
    \Else
        \State $\mathsf{filled}[i+1] \gets H(\mathsf{filledSubtrees}[i], \mathsf{filled}[i])$
    \EndIf
    \State $\mathsf{index} \gets \lfloor \mathsf{index} / 2 \rfloor$
\EndFor
\State Update root $R \gets \mathsf{filled}[d]$
\end{algorithmic}
\end{algorithm}

Gas cost: $d \times 4{,}000 = 80{,}000$ gas for $d = 20$ Poseidon hashes.
