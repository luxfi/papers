\section{Phase 2: Pattern Detection with Aderyn}


Aderyn is a Rust-based Solidity analyzer that detects domain-specific anti-patterns
that Slither misses. It is faster than Slither (Rust vs.\ Python) and focuses on
patterns specific to DeFi, bridges, and governance.

\begin{lstlisting}[language=bash,caption={Running Aderyn}]
# Install
cargo install aderyn

# Run analysis
aderyn .

# Output: report.md with findings by severity
\end{lstlisting}

Key patterns Aderyn detects that Slither misses:
\begin{itemize}[nosep]
  \item Centralization risks (single admin key controls protocol).
  \item Missing zero-address validation in constructors.
  \item Unsafe use of \texttt{block.timestamp} for time-sensitive logic.
  \item Missing event emissions for state changes.
  \item Inconsistent use of \texttt{SafeERC20}.
\end{itemize}
